# Privacy

## Current Policy

Handwriting Worksheet Generator does not include application telemetry, analytics, advertising, tracking pixels, user accounts, or a project-operated backend service.

The project is designed to process source text and custom fonts locally on the user's device. The current development application does not send worksheet content, file names, fonts, settings, or usage events to the project maintainers.

## Network Activity

The application may eventually provide links that open external websites, such as project documentation. Visiting an external website is governed by that site's privacy policy.

Downloading the application, cloning the repository, opening issues, or interacting with releases happens through GitHub and is subject to GitHub's own terms and privacy practices. Repository maintainers may see aggregate repository traffic, stars, forks, public issues, and public adoption reports. They cannot identify every person who downloads, clones, copies, or runs the software.

## Future Changes

Privacy is a project requirement, not an afterthought. If optional usage analytics are proposed in the future, they must:

- Be discussed publicly before implementation.
- Be disabled by default.
- Require informed, affirmative opt-in.
- Explain exactly what is collected and why.
- Avoid collecting worksheet text, file names, custom fonts, or other document contents.
- Provide an equally functional opt-out experience.
- Offer a clear way to withdraw consent.
- Be documented here before release.

No telemetry feature may be introduced solely to identify individual users.

## Sensitive Material

Worksheets may contain names, educational information, or other personal content. Users should avoid posting real worksheet contents, student information, or proprietary fonts in public issues. Bug reports should use invented or anonymized examples.

## Reporting a Privacy Concern

For a security-sensitive concern, follow [SECURITY.md](./SECURITY.md). For a non-sensitive policy suggestion, open a feature proposal.
