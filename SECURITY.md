# Security Policy

## Supported Versions

The project is in early development. Security fixes are applied to the latest code on the default branch. Published support guarantees will be documented when the first stable release is available.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/yehuawang/handwriting-worksheet-generater/security/advisories/new>

Include:

- A description of the issue and its potential impact.
- Reproduction steps or a proof of concept.
- Affected versions or commits, if known.
- Any suggested mitigation.

Please allow the maintainer a reasonable opportunity to investigate before public disclosure. You can expect an initial acknowledgement within seven days. Timelines for validation and remediation will depend on severity and project availability.

Security-sensitive areas include custom font parsing, local file access, PDF generation, Tauri permissions, and any future hosted file processing.
