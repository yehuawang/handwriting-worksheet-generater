# Support

This project is maintained by volunteers and does not currently provide guaranteed support.

- Use a bug report for reproducible software defects.
- Use a feature proposal for new ideas and workflow improvements.
- Use a question issue when documentation does not answer a development or usage question.
- Use a Share your use report to volunteer a public, non-sensitive adoption story.
- Follow [SECURITY.md](./SECURITY.md) for vulnerabilities.

Please do not include private student information, sensitive document contents, credentials, or proprietary fonts in public issues.
